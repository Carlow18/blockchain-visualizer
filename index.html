How It Works

  • Hash Linking: Each block contains the hash of the previous block, creating an immutable chain
  • Mining (Proof-of-Work): Finding a nonce that produces a hash with the required number of leading zeros
  • Tampering: Click on block data (yellow boxes) to edit it and see how it breaks the chain
  • Validation: The chain checks that each block's hash matches its content and links correctly
  • Re-mining: After tampering, you can re-mine individual blocks, but subsequent blocks will still be invalid
